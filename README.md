# 离散几何处理与应用 · 点化学习系统

《离散几何处理与应用》（鲍虎军、黄劲、刘利刚，2020）的点化学习知识库：把一本 351 页的扫描版专业书，拆成能零基础读下去的一套材料。

## 内容

- **9 章精讲**（原书目录实为 9 章）：数学基础、点云重建与光顺、参数化与多分辨率、重网格化、三维形状分析、曲面形变、弹性模拟、机器学习几何、新型应用
- **16 篇概念页**：离散拉普拉斯、高斯曲率、样条、ICP 配准、Voronoi-Crust、Poisson 重建、参数化、QEM 与渐进网格、交叉场、标架场与六面体、形状描述子、网格分割、蒙皮 LBS/DQS、梯度域与 ARAP、弹性模拟、稀疏与深度几何
- **术语表 101 条 / 测验 42 题 / 抽认卡 45 张 / 模式库 5 框架 6 规则 6 反模式 / 速查表 / 九步学习路径**
- **两篇「从零推导」单文件交互页**：网格上的微分几何、梯度域形变（KaTeX 连字体全内联，离线可读）

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` | 总学习手册，单文件离线可开，含全局搜索与进度保存 |
| `01-离散几何处理与应用/` | 单书知识库（Markdown 源 + manifest + 单书伴侣 HTML） |
| `从零推导/` | 两篇从零推导 HTML 与其源码片段、组装脚本 |
| `交付说明.md` | 目录用途、使用方法、验证结论、取舍说明 |

## 本地使用

双击 `index.html` 即可，无需服务器。

## 部署

GitHub Pages 从 `main` 分支根目录发布；仓库内已放 `.nojekyll`，中文目录名与 `_` 开头的目录可以原样托管。

## 说明

知识库是学习笔记式的转述与重构，原书版权归作者与出版方所有。原书为纯扫描件（无文字层），公式符号 OCR 破损严重，因此 Markdown 正文统一使用 Unicode 数学符号；两篇从零推导页使用 KaTeX。
