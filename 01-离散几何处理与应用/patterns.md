# 模式与框架库

这本书真正可迁移的不是具体算法，而是作者反复使用的几个分析框架，以及他明确反对的做法。下面把框架和规则抽出来，用的时候可以直接套。

## 框架一：三种表示的选择题

任何几何问题先问"我用哪种表示"：

| 表示 | 擅长的 | 不擅长的 |
|---|---|---|
| 多边形网格 | 渲染、编辑、拓扑明确 | 布尔运算、拓扑变化、光滑度 |
| 隐式（SDF/指示函数） | 布尔运算、重建、拓扑自适应 | 精确渲染、尖锐特征 |
| 参数（样条/NURBS） | 光滑曲面、工业 CAD | 任意拓扑、局部细节 |

**怎么用**：先问"这个任务需要拓扑变化吗"（需要 → 隐式）、"需要精确工业曲线吗"（需要 → 参数）、"只要渲染和编辑吗"（是 → 网格）。三者可以互相转换（Marching Cubes、参数化、拟合），所以真正的决策是"转换成本 vs 收益"。

## 框架二：局部微分 + 全局求解

这是全书出现频率最高的结构。所有变体都是同一条：

1. 定义一个**局部量**（拉普拉斯坐标、边长、法向、相似变换）；
2. 写一个"让新形状的局部量保持原局部量"的能量；
3. 求解 → 得到全局坐标。

| 出现位置 | 局部量 | 全局求解 |
|---|---|---|
| Poisson 重建 | 法向场 | Δf = ∇·V |
| 参数化 | 三角形形状 | 稀疏最小二乘 |
| 梯度域形变 | 拉普拉斯坐标 | L v' = b |
| ARAP | 边长 | 稀疏系统 + 旋转交替 |
| 投影动力学 | 约束投影 | 常量矩阵系统 |

**怎么用**：遇到"要改整体但保细节"的需求，先问"细节能被什么局部量表示"，再问"这些局部量是否可积"。不可积的部分必须投影掉（Helmholtz 分解），否则系统无解。

## 框架三：交替优化（局部-全局迭代）

固定 A 求 B，固定 B 求 A，循环到收敛。

- ASAP：旋转 ↔ 坐标；
- ARAP：每三角形旋转 ↔ 顶点位置；
- ICP：对应 ↔ 变换；
- 方向场：整数 ↔ 连续场（逐步取整）。

**怎么用**：只要能量能拆成"每对变量各自的最优子问题"，就可以交替。注意三个前提：每个子问题可解（闭式或凸）、整体能量单调下降、初值不离正确解太远。三者缺一，就会卡在坏的局部极小。

## 框架四：约束怎么进目标函数

三种写法，代价完全不同：

| 写法 | 例子 | 优点 | 缺点 |
|---|---|---|---|
| 硬约束（拉格朗日/KKT） | 固定控制点、锚点 | 精确满足 | 组合爆炸、可能不可行 |
| 软约束（惩罚项 λ） | 筛选 Poisson、权重正则 | 一定可解 | λ 难调，太大病态、太小不满足 |
| 归一化（比值目标） | Ncut、MIPS | 无需调参、自动平衡 | 目标非凸 |

**怎么用**：能写成归一化的，优先归一化（Ncut 就是范例）；必须精确满足又规模小的，用硬约束；规模大或可能不可行，用软约束并给出 λ 的敏感度分析。

## 框架五：从连续到离散的三次检查

离散化不是"把公式里的积分换成求和"。每次都要检查三件事：

1. **收敛性**：细分后是否趋于连续解？（均匀 Laplace 权重不满足，余切权重满足）
2. **不变量**：连续定理在离散下是否仍成立？（Gauss-Bonnet 对任意剖分成 2πχ）
3. **退化情形**：钝角、退化三角形、非流形边怎么处理？（钝角使余切为负）

**怎么用**：写完一个离散算子，先找它的连续原型定理，再验证"剖分加密时误差是否下降"。通不过第 1 条，算子就是错的。

## 决策规则

**R1 重建方法：干净数据用显式，脏数据用隐式。**
采样密、噪声低、要拓扑保证 → Crust/Cocone；有噪声、有缺失、要水密 → 筛选 Poisson。理由：显式方法依赖精确的 Delaunay 结构，噪声会改变结构本身。

**R2 参数化：先保证不翻，再减少扭曲。**
Tutte（正权重 + 凸边界）给可行初值；再用 ASAP/MIPS 优化；如果优化中翻转，减小步长或加障碍项。顺序不能反。

**R3 简化：误差预算驱动，而不是面数驱动。**
先定"允许的 Hausdorff 误差"，再让 QEM 跑到预算边界；QEM 的二次型天然就是误差上界估计。

**R4 形变：小变形用线性，大变形用非线性。**
线性（梯度域）快但关节会塌；非线性（ARAP + 体积约束）慢但不塌。判断标准：旋转角是否超过约 45°、是否有明显弯曲。

**R5 模拟：先定时间预算，再选积分器。**
需要毫秒级 → PBD 或投影动力学；需要物理准确 → 隐式 + 有限元；需要多次材质迭代 → 子空间 + Cubature。

**R6 学习：先问"数据够不够"，再问"要不要保证"。**
数据少 → 手工特征 + 浅层模型；数据多但要保证不自交/不翻转 → 学习 + 后处理投影；数据多且只要"像" → 端到端生成。

## 反模式（作者明确反对或反复警告的）

**A1 "把网格加密就能提精度"。**
错在：加密后刚度、权重、时间步都要重标定，不重标定等于换了一个物理系统。正确做法：按边长重标定弹簧刚度，或改用连续介质参数。

**A2 "一次性取整整数变量"。**
错在：远离整数的分量被硬拉过去，奇异点爆炸、场极不光顺。正确做法：先解连续松弛，再逐步固定最接近整数的部分，迭代优化剩余。

**A3 "直接对向量场积分"。**
错在：一般向量场不可积（含旋转分量），积分结果依赖路径。正确做法：先取散度再解 Poisson（Helmholtz-Hodge）。

**A4 "先光顺再重建"。**
错在：光顺需要法向/邻域，而点云没有可靠邻域；顺序反了会把结构一起抹平。正确做法：先重建（或先做 MLS 投影 + 法向估计），再对网格光顺。

**A5 "把三角形特征重排成矩阵就当图像处理"。**
错在：排列与拓扑邻接无关，换顺序结果就变，违背"几何处理应尊重曲面结构"的初衷。正确做法：用测地邻域/切平面分箱（流形卷积），或至少按参数化展开。

**A6 "用学习模型替代所有几何算子"。**
错在：网络不保证体积守恒、不自交、力平衡。正确做法：网络负责"先验/残差/加速"，硬约束交给投影与优化。
