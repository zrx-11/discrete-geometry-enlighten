## 二、常用流程

**A. 点云到网格（扫描数据）**

```
1. 多视角配准：特征粗配准（FPFH + RANSAC）→ ICP 精修
2. 法向估计 + 去噪：MLS 投影 或 法向双边滤波
3. 隐式重建：八叉树 + 筛选 Poisson（λ 由 0.1 起调）
4. 抽等值面：Marching Cubes
5. 网格后处理：保特征光顺（Taubin）、简化（QEM）
```

**B. 网格到纹理坐标（参数化）**

```
1. 切缝：沿曲率脊线，总长度尽量短
2. Tutte 初值：边界→凸多边形，正权重
3. 优化扭曲：ASAP 或 MIPS（带防翻转）
4. 检查：最大角度扭曲、最大面积扭曲、有无翻转
5. 打包：多片排布到 [0,1]²（bin packing）
```

**C. 网格到四边形**

```
1. 估交叉场：切向空间 + (cos4θ, sin4θ) 光顺，约束特征对齐
2. 求整数跳跃（逐步取整），检查奇异点指数总和 = χ
3. 全局参数化：整数格点约束
4. 抽网格：按格点连线，修退化单元
5. 优化：局部拓扑操作（翻转边、合并）
```

**D. 形变**

```
1. 选能量：小变形 → 梯度域；大变形 → ARAP + 体积
2. 定约束：控制点/骨架/碰撞
3. 交替求解至收敛（残差 < 1e-4）
4. 检查：有无自交、体积变化率、局部翻转
```

**E. 模拟**

```
1. 建模：弹簧 / 有限元（材料参数与网格无关）
2. 积分：显式（h 由 ω_max 定）或隐式（预分解）
3. 加速：子空间（K = 20—60 模态）/ 投影动力学 / Cubature
4. 碰撞：BVH 检测 → 约束处理（位置修正或 KKT）
5. 输出：每帧位置 + 速度（可再驱动材质反演）
```

## 三、参数判据与经验值

| 参数 | 经验值 | 说明 |
|---|---|---|
| 保特征光顺 λ | 0.3—0.7 | 越大越保形，太小不光滑 |
| 双边滤波 σ_r | 约 0.5—1 倍平均边长 | 决定"跨棱是否被抹平" |
| ICP 收敛阈值 | 相对误差变化 < 1e-3 | 太严会空转 |
| 筛选 Poisson λ | 0.1—1 | 大则贴合噪声，小则平滑过细节 |
| 八叉树最细层 | 约 1/256 到 1/512 包围盒 | 小于此的细节会被抹掉 |
| QEM 目标 | 按误差预算（如 Hausdorff 1% 边长） | 不按面数定 |
| ARAP 迭代 | 5—15 次 | 通常 10 次内收敛 |
| 子空间模态 K | 20—60 | 大幅动作需更多 |
| PBD 迭代 | 10—30 次/帧 | 刚度靠迭代堆 |
| 显式步长 | h ≤ 2/ω_max，实际取 0.5 倍 | 留安全余量 |
| 碰撞约束簿 | 每顶点最多 1 个 | 让矩阵对角，视觉几乎无损 |
| 悬垂支撑阈值 | 45° | 低于此需支撑 |
| 重定向平移增益 | 0.6—1.6 | 个体差异大，需实测 |
| 四边形密度场 | g = exp(G)，G 对称 | 保证正定 |

## 四、常见数值校验

- 闭合网格上 ΣK_i 应等于 2πχ；不等于说明拓扑有问题。
- 正四面体每顶点 K = π，总 4π（对应 χ = 2）。
- 等边三角形 cot60° = 0.5774，两侧权重 1.1547；A = 0.4330 → 系数 1.333。
- 球面 HKS 在 t=1 约 0.113，t=10 约 0.0796（趋于 1/(4π)）。
- 100 顶点走廊切 1 点 Ncut ≈ 1.01，中切 ≈ 0.04。
- LBS 90° 旋转、权重 0.5/0.5 → 距离 0.707r。
- 四边形球面奇异点指数总和必须为 2（至少 8 个 3 价）。
- 1D L1：y=1、λ=2 → 解 0；λ=0.3 → 解 0.85（L2 为 0.769）。
- 梯度域 1D：δ=(1,0,0,−1)，固定 0 与 2 → x2=2/3、x3=4/3。
