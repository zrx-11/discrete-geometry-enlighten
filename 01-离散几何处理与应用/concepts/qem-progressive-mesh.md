# QEM 简化与渐进网格

- **难度**：进阶 | **涉及章节**：第 3 章

## 一句话定义

用"删掉这条边后新顶点到原来若干平面的距离平方和"评估每次边坍缩的损失，选损失最小的先坍缩；把整个坍缩序列倒过来存，就是渐进网格。

## 为什么重要

它是"误差可累加"的典范：一次坍缩的误差能被新顶点继承，所以整个简化过程的误差可以量化控制。第 3 章的多分辨率、第 8 章的粗化预处理都以它为基座。

## 图示

```mermaid
flowchart TD
    A[原始网格] --> B[为每个顶点建二次型 Q]
    B --> C[对每条边算 (Qi+Qj) 的最小值]
    C --> D[优先队列取最小]
    D --> E[坍缩 更新邻域 Q = Qi+Qj]
    E --> F{达到目标边数?}
    F -->|否| C
    F -->|是| G[粗网格 + 坍缩记录]
    G --> H[反序执行 = 渐进网格]
```

看图说明：右边的"反序执行"是关键——简化过程本身就是可逆的多分辨率结构，不必另外建层次。

## 详解

**二次型**（难度：进阶）。每个顶点维护

```
Q_i(x) = Σ_{p ∈ planes(i)} (n_pᵀ x + d_p)² = xᵀ A_i x + 2 b_iᵀ x + c_i
```

用齐次坐标写成 4×4 矩阵 Q_i，则"点 x 的误差"= xᵀ Q_i x（x 取齐次形式 (x, y, z, 1)）。这条式子的意思是"点到与该顶点相关的所有平面的距离平方和"——平面包括相邻三角形的支撑平面。

**边坍缩的最优位置**（难度：进阶）。把边 (i, j) 合成一个顶点，误差约等于 (Q_i + Q_j)(x̄)。对 x̄ 求极小：解 3×3 线性系统

```
(A_i + A_j) x̄ = −(b_i + b_j)
```

若矩阵奇异（退化情形），退回到"取 i、j 或中点"这几条候选，选误差最小者。算完得到该边的"坍缩代价"，放进优先队列。

**为什么平面先被简化**（难度：进阶）。平面上所有顶点都在同一组平面内，误差恒为 0。于是平面区域的边代价为 0，最先被坍缩；直到平面被压到只剩边界，代价才开始上升。而 90° 棱边上的顶点同时属于两个差异很大的平面，误差不为 0，被留到最后。**这就是"平面先塌、特征后动"的机制**，不是靠手工规则。

**渐进网格 PM**（难度：进阶）。把坍缩序列倒过来：每条坍缩记录包含"被删的两个顶点编号、新顶点位置、受影响的三角形"。从粗网格出发，逐条执行分裂（vsplit），就能得到任意精度的模型。

- 存储：粗网格 + k 条记录，比存多个 LOD 省；
- 任意分辨率：不是只支持 2—3 档，而是连续可调；
- 误差可控：每条记录都带误差值，可按预算停止。

**边界与属性**（难度：进阶）。实际实现要处理：边界边（不能随便坍缩，否则轮廓变形）、属性（纹理坐标、法向要一起插值）、非流形（要保护）、自交（坍缩后要检查）。

## 常见误解

- **别以为"QEM 只是启发式，没有理论"**——实际上它是最小二乘近似下的最优位置选择，误差单调可加，是"贪心但可控"的典型。
- **别以为"误差为 0 的边可以无限坍缩"**——实际上平面区域确实会被压到极小，但要保留至少一个三角形（否则拓扑丢失）；实现里要加"不产生非流形/不删光面"的保护。
- **别以为"简化到很低面数还能保住细节"**——实际上 QEM 保的是"到平面族的距离"，对尖锐特征（棱、尖角）只能保住位置，保不住细节形状（那需要特征保持的变体，如加特征边约束）。
